# Khronos animation fixture

`BoxAnimated.glb` is the unmodified Box Animated model by Cesium, copyright
2017. It is licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/legalcode).
The original attribution names Cesium for everything.

Source: [Khronos glTF Sample Assets, BoxAnimated](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/5bad5aaa0bbb5d0f9cdc934e626f27d0df1e79b8/Models/BoxAnimated).
Retrieved 28 September 2026. SHA-256:
`ad0d18d9a21df0d7c2bd3890e60ce69d60d39a55d9b82bacea7e77ac9e583839`.

We use its unequal rotation and translation timelines to check that a shorter
channel holds its final pose until the entire clip loops. The model and its
animation data have not been changed. Native preview renders add viewer lights.
