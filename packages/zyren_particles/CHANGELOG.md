# Changelog

## 0.1.0

- Add native GPU simulation, a Dart reference path, fixed-step emission and
  deterministic seeds with bounded overflow behavior.
- Add point, box, sphere, cone and triangle-surface emitters; curves, gradients,
  atlas textures, noise and flow forces, and plane or box collisions.
- Render billboards, oriented and stretched quads, unlit meshes and ribbons with
  alpha sorting, additive blending, depth controls and scene clipping.
- Add independent plugin ownership, atomic configuration, prewarm, playback
  controls, explicit inspection and resource restoration.
- Add Particle Lab, native image comparisons and maximum-capacity qualification.
  See the qualification record for tested platforms and unsupported soft depth.
