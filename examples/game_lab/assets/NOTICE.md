# Character fixture source

The authored two-leg character fixture is copied from
`packages/zyren_characters/example/app/lib/skinned_character_asset.dart` in this
repository. It generates the imported glTF skin, bind matrices and walking clip
from repository-owned geometry and animation data. No third-party character,
texture or motion-capture assets are included.

Keep this notice with the fixture when you copy it into another example.
