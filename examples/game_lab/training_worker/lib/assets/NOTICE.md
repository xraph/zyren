# Character fixture source

This repository-owned fixture generates the two-leg glTF skin, bind matrices
and walking clip used by native character tests and the training worker. The
source came from `packages/zyren_characters/example/app/lib/skinned_character_asset.dart`.
It contains no third-party character, texture or motion-capture assets.

The old GameLab asset path exports this helper. Keep the notice with it.
