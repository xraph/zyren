# Explicit 3D Tiles streaming

You can load an explicit 3D Tiles 1.0 or 1.1 tileset and stream its GLB or b3dm
content through the native renderer. Keep this in an optional `zyren_3d_tiles`
package over public core, glTF and geographic math APIs. Work on main as requested.

## Task 1: Manifest and content

Use the CesiumGS 3D Tiles specification and b3dm layout as format references.
Add bounded manifest parsing with arbitrary children, inherited ADD/REPLACE,
affine transforms, sphere/box/region bounds and resolved content URIs. Scale
geometric error conservatively under transforms. Regions remain in WGS84.
Decode direct glTF/GLB and b3dm through the existing glTF loader, with its Y-up
conversion and RTC translation in the specified order. Check padded GLB lengths.

Reject implicit tiling, external tilesets, multiple contents, viewer request
volumes and required unsupported extensions. Batch metadata can be rendered
without feature styling; document that limitation. No provider authentication.

Write format tests first. Expected: missing API fails. Implement and run the
new package and glTF suites. Expected: pass. Commit the checked format layer.

## Task 2: Streaming and scene lifecycle

Add arbitrary-tree selection by screen error, ADD and REPLACE coverage,
parent fallback, frustum culling and byte/request budgets. Keep empty internal
nodes traversable. Retain cancelled request slots until their actual reads and
decode settle, even when a host resolver ignores cancellation. Cache CPU models
with explicit eviction and preserve their asset scopes until release.

Expose a scene plugin with source replacement, capped explicit retries and
asynchronous status. Write failure, cancellation, replacement, cache and coverage
tests first. Expected: fail without the streamer. Implement and run all package
tests. Expected: pass. Commit.

## Task 3: Native fixture and example

Add a compact runnable example and synthetic HTTP tileset fixture. Test native
Metal rendering, transforms, refinement, failure/retry, resize and cleanup.
Run analysis, package boundaries and affected suites. Expected: pass. Review
the complete owned diff with one fresh-context reviewer and fix material
findings with regressions. Update the roadmap and parity evidence, then commit.

## Review focus

Check transform order and Earth-scale precision, conservative bounds under
nonuniform scale/shear, empty-node coverage, ADD under REPLACE parents, physical
request cancellation accounting, encoded and decoded budgets, malformed binary
lengths and nested JSON limits. No unsupported tileset feature may silently
change traversal. Native Metal fixtures do not establish provider or mobile
compatibility. Budgets cover logical payloads, not process RSS or driver overhead.
